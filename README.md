## 🛠️ Hướng dẫn xem mã nguồn tại máy cục bộ

1. Clone repo:
   ```bash
   git clone https://github.com/buihuuan2005/web-bootcamp-projects.git
   ```
2. Mở file `index.html` của từng thư mục trên trình duyệt hoặc dùng Live Server trong VS Code.
